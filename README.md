# Лабораторная работа №1. Шифрование изображений

## Требования
- Python 3.x
- Библиотеки: `Pillow`, `numpy`, `pycryptodome`, `scipy`, `matplotlib`.
Установка:
pip install pillow numpy pycryptodome scipy matplotlib

## Запуск
1. Исходное изображение `my_photo.png` должно лежать в папке `imgs/`.
2. Запустите скрипт: `python src/main.py`.
3. Результаты сохранятся в папки `imgs/` и `results/`.
